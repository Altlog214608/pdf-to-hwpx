3. Cross-PDF preparation
   - Question numbers are auto-detected when -q is omitted; 1~20 is no longer hard-coded at CLI level.

   - Choice-icon training uses the first detected question header rather than hard-coded question 1.
   - Choice-icon training uses the first detected question page rather than hard-coded PDF page 1.
   - The source-specific golden text regression check is limited to the known reference title rather
     than every filename containing '[최다빈출 공략]'.

4. Output naming
   - Default HWPX: <source PDF stem>.hwpx
   - Default JSON: <source PDF stem>_result.json
   - Existing output is never overwritten; _run02, _run03, ... is allocated automatically.
   - --hwpx-output and -o still override the defaults.
