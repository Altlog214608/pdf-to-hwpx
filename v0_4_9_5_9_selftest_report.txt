V0.4.9.5.9 SELF-TEST REPORT
============================

Target source
-------------
- v0_4_9_5_8_pdf_parser_integrated(1).py
- cumulative upgrade; existing stable image/two-column/security pipeline retained

Implemented changes
-------------------
1. Connected <보기> box
   - <보기> title paragraph AND the actual example body paragraph receive the same solid borderFill.
   - Both paragraphs use connect=1.
   - Final validator checks exact example body text, same border fill, solid four-side border, and connect=1.

2. Atomic question flow for one-column-fit questions
   - source geometry + conservative reflow estimate determines question height.
   - if estimated to fit one column: question stem + example title/body + choices ①~⑤ are one keepWithNext chain.
   - if current column lacks room, Hangul moves the whole question block to the next column/page rather than leaving a partial question.

3. Oversize-only safe splitting
   - only questions estimated taller than one usable column use split_safe_oversize.
   - stem/example remain semantically grouped.
   - each choice has keepLines=1 and breaks are allowed only BETWEEN whole choice paragraphs.

4. Final-HWPX integrity validator
   - validates all question stems exist.
   - validates exact ①→②→③→④→⑤ order.
   - validates <보기> title + full body are contiguous and both inside one connected solid border.
   - validates atomic/split-safe keepWithNext/keepLines policy from the final HWPX paraPr styles.

5. Cross-page / cross-column metadata
   - each passage block now stores source_start_page/source_start_column and source_end_page/source_end_column.
   - crosses_page_or_column flag is derived and validated.

6. Spacing cleanup
   - fixes confirmed residual cases conservatively, including:
     * '보기 어려운것은' / '보 기 어려운것은' -> '보기 어려운 것은'
     * '적절하지 않은것은' -> '적절하지 않은 것은'
     * '’며인생' -> '’며 인생'
   - no whole-sentence re-spacing was reintroduced.

7. Underline detector performance
   - vector-drawing underline scan is limited to passage groups actually referenced by ⓐ~ⓩ / ㉠~㉿ / (a)~(z)-style question markers.
