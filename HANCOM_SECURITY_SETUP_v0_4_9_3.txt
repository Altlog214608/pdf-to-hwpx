v0.4.9.3 한컴 무조작 HWPX 보안 설정
======================================

목표
- 한글 Automation의 파일 접근/저장 승인 팝업을 자동 클릭으로 우회하지 않습니다.
- 한컴에서 배포하는 공식 FilePathCheckerModuleExample.dll + RegisterModule 방식을 사용합니다.

최초 1회 준비
1. 한컴디벨로퍼의 '한글 오토메이션 > 보안 승인 모듈'에서 보안모듈(Automation).zip을 받습니다.
2. 압축 안의 FilePathCheckerModuleExample.dll을 아래 중 한 곳에 둡니다.
   - v0_4_9_3_pdf_parser_integrated.py와 같은 폴더 (가장 간단)
   - .\security\FilePathCheckerModuleExample.dll
   - C:\HncSec\FilePathCheckerModuleExample.dll
   - 또는 실행 시 --security-module "DLL전체경로"
3. 그 다음부터 일반 실행 명령만 사용하면 됩니다.

v0.4.9.3 자동 처리
- DLL을 찾으면 %LOCALAPPDATA%\HncSec\FilePathCheckerModuleExample.dll 로 안정 복사
- HKCU\Software\HNC\HwpAutomation\Modules\FilePathCheckerModuleExample 를 자동 등록
- HwpObject 생성 직후, 파일 접근/저장 전에
  RegisterModule("FilePathCheckDLL", "FilePathCheckerModuleExample") 호출
- 반환값 True를 확인한 뒤 한글 창을 숨기고 HWPX 생성
- False면 기본 모드에서는 즉시 중단하여 숨은 승인창에서 무한 대기하지 않음

예외/진단 옵션
- --allow-interactive-hwp : 공식 모듈 실패 시 기존처럼 승인창을 보여주며 계속
- --show-hwp              : 공식 모듈 성공 후에도 한글 창을 표시
- --security-module PATH  : 공식 DLL 경로를 직접 지정

중요
- DLL은 한컴에서 배포한 공식 모듈을 사용하세요.
- v0.4.9.3 코드는 DLL을 인터넷에서 자동 다운로드하지 않습니다.
- RegisterModule이 False면 JSON의 hancom_security_v0493.diagnostics를 확인하세요.
